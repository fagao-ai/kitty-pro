## Bug Fixes

- **Android: starting the proxy could fail and connect nothing.** With TUN mode
  switched on, 启动代理 answered 准备 TUN 权限失败，内核未启动 and the core never
  started. That pre-flight belongs to the desktop, where a privileged helper
  raises the network interface; a phone gets its interface from the VPN
  permission dialog instead, so it was being asked to prepare something that
  does not exist on Android. It is fixed where the decision is made, not only on
  screen: a phone that restored or synced a profile from a desktop was blocked
  the same way by a setting it had no screen to look at.
- **Android: 测试连通 ran off the right edge of the screen** on the overview
  page, so the button was half outside the window.
- **Android: the settings page no longer shows controls a phone has no use
  for.** TUN mode is gone — a phone always runs through its VPN tunnel and never
  chooses — along with the system-proxy switch, which has no setting behind it on
  Android, and the empty 启动与终端 card, whose one row is a login item a phone
  cannot have. 允许局域网连接 stays, because on a phone it is a real choice: it
  decides whether other devices on your network may use the proxy.
- **Android: the rules page no longer tells you to turn TUN on**, for the same
  reason.
- The settings search no longer offers those removed controls.

The web page loses the same empty 启动与终端 card, for the same reason: it has no
login item either. Nothing else on desktop or web changes — the TUN switch, the
system-proxy switch and the login item are all still there, because all three mean
something on those platforms.

## 修复

- **Android：点「启动代理」可能失败、什么都连不上。** 开启 TUN 模式后，会提示
  「准备 TUN 权限失败，内核未启动」，内核不会启动。这个预检属于桌面：桌面需要一个
  特权助手来创建网络接口；手机的网络接口来自 VPN 授权弹窗，因此手机被要求准备一个本
  不存在的东西。修复落在决策处而不只是界面上：手机从桌面恢复或同步过来的配置同样会
  被卡住，而它在手机上根本没有对应的开关。
- **Android：总览页的「测试连通」按钮会超出屏幕右边界**，只露出一半。
- **Android：设置页不再出现手机用不到的控件。** TUN 模式已移除——手机始终走自己的
  VPN 隧道，不存在选择；系统代理开关也已移除——Android 没有这个设置项；以及只有一
  行空内容的「启动与终端」卡片，那一行是手机无法拥有的登录启动项。「允许局域网连
  接」保留，因为在手机上它是一个真实的选择：决定局域网内其他设备能否使用代理。
- **Android：规则页不再提示去开启 TUN**，理由同上。
- 设置页的搜索也不再给出这些已移除的控件。

网页端同样去掉了那张空的「启动与终端」卡片，理由一样：它也没有登录启动项。桌面与
网页端的其余部分不变——TUN 开关、系统代理开关和登录项都还在，因为在这两个平台上它
们都有意义。
