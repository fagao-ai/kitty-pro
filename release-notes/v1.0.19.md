## Bug Fixes

- **The rules page fits a phone again.** Adding or editing a routing rule
  opens in a page sheet instead of expanding the page itself, so the form,
  its helper text, and its Add/Save button stay on screen. On a phone, each
  rule now uses two lanes: the rule value and its kind/action badge above,
  with the enable switch and move-up, move-down, edit, and delete actions
  below. The row no longer runs past the right edge, and desktop keeps its
  single-line layout.

## 修复

- **规则页在手机上不再被撑出屏幕。** 添加或编辑分流规则改为弹窗展示，不再
  把页面本身撑高，表单、说明文字和「添加/保存」按钮都留在屏内。手机上的
  每条规则改成两行：上一行显示规则内容、类型和动作，下一行放启用开关以及
  上移、下移、编辑、删除按钮，不再横向超出屏幕；桌面端仍保持单行布局。
