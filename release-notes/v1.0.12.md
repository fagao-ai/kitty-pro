## Features

- Settings has a search box: type a keyword to filter the setting groups.
- The sidebar is grouped into Connect / Configure / Operate for faster
  orientation.
- First launch now follows your system light/dark preference; an explicit
  in-app choice still wins and is remembered.
- Segmented controls (routing mode, sync provider, …) are fully keyboard
  navigable: Tab enters once, arrow keys / Home / End move the selection.
- The overview card folds secondary facts (version, uptime, DNS overrides)
  behind a details row so the connect button stays the focus.

## Bug Fixes

- Windows: a crash during a configuration save could leave both the old and
  the new profile file missing. Saves are now atomic with a verified backup
  and rollback, on every platform.
- Subscription URLs with embedded tokens were echoed in plain text in an
  overview detail and in some error toasts; all displayed and logged URLs are
  redacted now.
- The system dark-mode detection no longer overrides a theme you had already
  saved.
- Clash YAML subscriptions could be rejected or, in crafted files, expand
  into an anchor bomb via non-ASCII anchor names; the parser now handles both
  correctly.
- On some Windows setups a crafted value could break out of the PowerShell
  helper scripts; all interpolated values are escaped now.
- Dark theme: faint text and disabled buttons had contrast below WCAG AA;
  both now pass the automated axe scan.
- The overview page could overflow the fold on 700px-high windows, forcing
  a scroll just to reach the connect button.
- `sing-box` config validation errors no longer echo node passwords back
  into the log.

## Improvements

- Error messages carry stable codes (`[E1001]` …) so support reports can
  name the failure instead of a wall of translated text.
- Background polling (logs, update checks, process list) is skipped while
  its page is not open, cutting idle network traffic.
- Accessibility: icon buttons gained labels, async buttons report busy state,
  and the log stream announces updates to screen readers.

## 新功能

- 设置页新增搜索框，输入关键词即可过滤设置分组。
- 侧边栏按「连接 / 配置 / 运维」分组，定位更快。
- 首次启动跟随系统深浅色偏好；应用内手动选择优先并被记住。
- 分段控件（分流模式、同步服务等）支持完整键盘操作：Tab 一次进入，方向键 / Home / End 切换。
- 概览卡片把次要信息（版本、运行时长、DNS 覆盖）折叠进详情行，突出连接按钮。

## 修复

- Windows：保存配置过程中断电或崩溃，可能同时丢掉新旧两份配置文件。现在所有保存均为原子写入，带备份与回滚，全平台生效。
- 概览详情与部分错误提示中会明文回显带 token 的订阅 URL，现已全部脱敏。
- 系统深色模式检测不再覆盖你已保存的主题选择。
- Clash YAML 订阅对非 ASCII 锚点名要么误拒、要么被构造文件触发锚点炸弹，解析器已修正。
- Windows 上构造的取值可能破坏 PowerShell 辅助脚本，所有插值现已转义。
- 深色主题下弱化文字与禁用按钮对比度低于 WCAG AA 标准，现已通过 axe 自动扫描。
- 700px 高的窗口里概览页会超出折叠线，需要滚动才能点连接到按钮，已修复。
- sing-box 配置校验报错不再把节点密码回显到日志里。

## 优化

- 错误消息携带稳定错误码（`[E1001]` 起），反馈问题时可直接报码而非翻译文本。
- 页面未打开时不再后台轮询日志、更新与进程列表，降低空闲流量。
- 无障碍：图标按钮补齐可访问名称，异步按钮上报忙碌状态，日志流更新可被读屏软件播报。
