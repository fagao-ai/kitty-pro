## Features

- **桌面版回归系统托盘。** 右下角通知区重新出现 Kitty Pro：右键菜单可以切换订阅
  与节点、开关系统代理、复制代理环境变量、唤回主窗口，或真正退出。关闭窗口现在
  是隐藏到托盘而不是结束进程——内核与代理继续运行，托盘「退出」才是唯一的退出，
  退出时照旧清理系统代理。托盘状态实时跟随应用：悬停提示显示连接状态与当前节点，
  菜单里的 ● / ○ 标记当前订阅与节点，切换语言后菜单随之改变。macOS 上菜单栏图标
  沿用模板染色，Windows 上使用白色图标以在深色任务栏上可见。
- **Windows 发布新增 MSI 安装包。** 除了便携 zip，这次起 Release 页附带
  `Kitty-Pro-windows-x86_64.msi`：标准安装向导、装入 Program Files、开始菜单
  快捷方式、新版本原地升级。应用内更新检查本就优先安装包，因此 Windows 用户现在
  会被直接指向 MSI。

## Bug Fixes

- **Windows 版的内核回来了。** 此前的 Windows 包里只有主程序——MSVC 构建的
  sing-box 内核是独立的 `kitty_singbox.dll`，而打包流程并不知道这一对，发布的
  zip 缺了它，应用能打开但内核永远不可用。现在发布流程会把 DLL 放进 zip（并校验
  其存在），与 macOS、Android 不受影响的原因（内核静态链接或已打包）互为印证。
- **Windows：页头不再被窗口控制按钮压住。** 最小化、最大化、关闭三个按钮位于窗
  口右上角，直接叠在页头右侧的主题切换按钮和连接状态胶囊上（macOS 的红绿灯在左
  上角，无此问题）。现在 Windows 上这一行控件下移，避开按钮区，其余平台布局不变。
- **Windows 托盘退出后不再残留进程。** 托盘退出路径此前会把进程留在后台；升级
  NSH 0.5.1 后，退出即干净结束。
- **发布包升级至 NSH 0.5.1。** 与 `packages/nsh-app` 的 crate 版本同步，运行时
  与 Rust 两侧保持一致。
