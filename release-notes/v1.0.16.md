## Features

- **macOS now ships a disk image.** The release carries
  `Kitty-Pro-macos-aarch64.dmg` beside the existing zip: open it, drag
  `Kitty Pro.app` onto `Applications`, done. Until now the zip was the only
  option, which meant unzipping and finding the right folder yourself. The zip
  stays for anyone who unpacks the app from a script, and the in-app update
  check points a Mac at the image.

## Bug Fixes

- **Quitting a packaged desktop build no longer leaves the system proxy on.**
  退出 from the Dock menu closed the app and left the machine's web and HTTPS
  proxies pointing at a port nothing was answering any more, so browsing broke
  until the proxy was cleared by hand. The next launch used to fix it; now the
  quit itself does.
- **Android: 运行时长 and the traffic chart no longer freeze.** After 启动代理
  the overview kept saying 运行中 above a `00:00` uptime and a flat chart, with
  no traffic figures at all. The one reading that feeds both gave up permanently
  on its first attempt, which on a phone is every time, because the VPN
  interface is still coming up. The figure is also measured off the clock now
  rather than counted per reading, so it cannot stall behind a slow core.
- **macOS: 启动 TUN stops failing at random.** Starting the network interface
  intermittently answered 连接失败 even when everything was in order. The
  request reached the privileged helper before it had finished arriving, and the
  helper read that as a failure instead of waiting. It now works out whether the
  same action succeeds or fails on luck, and it fails consistently no more.
- **The routing rule's action tag sat too high in its row.** 直连, 拦截 and 代理
  on the rules page floated above the line they belong to, and the same is true
  of the DNS rows.
- **The reconnect banner keeps its button on screen.** When a local change is
  waiting to be applied, 总览 shows a banner with 重新连接; in English that
  button was laid outside the right edge of a phone screen, so the one action
  that applies the change could not be reached.
- **Re-checking the core no longer resets 运行时长.** Pressing 重新检测内核 on a
  healthy core zeroed the uptime and left a second reader running beside the
  first, which halved every rate in the traffic chart.

## 新功能

- **macOS 现在提供磁盘镜像。** 发行版在原有 zip 之外附带
  `Kitty-Pro-macos-aarch64.dmg`：打开后把 `Kitty Pro.app` 拖进「应用程序」即可。
  此前只有 zip 一种选择，需要自己解压再找目录。zip 继续保留，供脚本解压使用；
  应用内的更新检查会把 Mac 指向磁盘镜像。

## 修复

- **桌面版退出后不再残留系统代理。** 从 Dock 菜单「退出」后，整机的 Web 与
  HTTPS 代理仍指向一个已经没人在听的端口，浏览器因此无法上网，只能手动清掉。
  以前要等下次启动才恢复，现在退出时就会清理。
- **Android：运行时长与流量图不再卡住。** 点「启动代理」之后，总览会一直显示
  「运行中」，但运行时长停在 `00:00`、流量图是平的，也读不到流量数字。同时供
  这两处使用的读取在第一次尝试失败后就彻底放弃，而手机上每次都会失败——因为 VPN
  接口那时还没建立起来。现在时长按时钟计算，而不再按读取次数累加，不会因为内核
  响应慢而停滞。
- **macOS：「启动 TUN」不再随机失败。** 创建网络接口时偶发返回「连接失败」，而
  一切其实正常。请求还没发完，助手就去读了，并把这个情况当成失败而不是等待。现
  在不靠运气了：以前同一操作可能成功也可能失败，现在不会莫名失败。
- **规则页的动作标签不再偏高。** 分流规则上的「直连」「拦截」「代理」浮在所在行
  上方，DNS 行同理。
- **「重新连接」横幅的按钮回到屏幕内。** 本地改动尚未生效时总览会出现带「重新连
  接」的横幅；英文界面下这个按钮被排到手机屏幕右边界之外，导致唯一能让改动生效的
  操作点不到。
- **重新检测内核不再把运行时长清零。** 内核正常时按「重新检测内核」会把时长归零，
  并在原有读取旁再启动一个，使流量图里的速率被算成一半。
