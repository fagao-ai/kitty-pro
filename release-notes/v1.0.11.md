## Improvements

- The interface code was restructured into per-concern modules; behaviour is
  unchanged and the app ships the same feature set as before.

## Bug Fixes

- The power button now lights up only while the core is actually running, and
  a configuration change is honestly reported as pending until a reconnect
  applies it.
- The runtime status shown on the overview page has a single source of truth,
  so panels can no longer disagree about whether the proxy is connected.

## 优化

- 界面代码按职责重构为独立模块，功能与操作方式与之前完全一致。

## 修复

- 电源按钮现在只在内核真正运行时点亮；修改配置后会如实提示「重新连接后生效」。
- 概览页的运行状态只有一个来源，各面板不会再对「是否已连接」出现互相矛盾显示。
