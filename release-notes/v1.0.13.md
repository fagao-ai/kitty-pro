## Bug Fixes

- Nodes page: switching away and back could briefly show "no proxy groups in
  the configuration" until a slow recalculation finished; the list now stays
  visible across navigation, and the (heavier than it looked) preview request
  only re-runs when your subscription or connection config actually changes.
- Windows: a privileged core startup check that blocks cache files in
  world-writable locations only recognised POSIX paths — `C:\Windows\Temp`
  and drive roots were let through. The blacklist now covers the Windows
  locations and matches case-insensitively, as Windows paths demand.

## Improvements

- Every desktop installer (dmg, AppImage, deb included) now ships with a
  `.sha256` sidecar on the release page, matching the Windows/Android/Web
  assets.

## 修复

- 节点页：切换页面再切回来时，列表会短暂显示「配置中没有代理组」，要等重算完成才出现。现在导航过程列表保持可见，且代理组预览只在订阅或连接配置真正变化时才重新计算。
- Windows：特权模式下拦截「缓存文件放在全局可写目录」的安全检查此前只识别 POSIX 路径，`C:\Windows\Temp` 与盘符根目录会被放行；现已补全 Windows 位置并按 Windows 语义做大小写不敏感匹配。

## 优化

- 发布页所有桌面安装包（含 dmg、AppImage、deb）均附带 `.sha256` 校验文件，与 Windows / Android / Web 产物一致。
