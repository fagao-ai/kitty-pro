## Features

- **Subscriptions can now be edited.** Each row on the subscriptions page
  gains a pencil: it opens the import form prefilled with the row's own name
  and source, and saving updates that subscription in place — same row, same
  id, same active state. When a provider changes its URL (or adds parameters,
  as obfs setups do), updating is no longer delete-and-re-add. A source that
  fails to parse keeps the dialog open with the reason, exactly like an
  import; a node the new source no longer contains falls back the way a
  refresh's does; and saving while the core is running reports that the
  change applies after reconnecting.
- **Port hopping ranges are understood.** A hysteria2 link (or a Clash yaml
  proxy) that carries a hop range — `mport=20000-50000` in a URI, `ports:` in
  yaml — now reaches the core as `server_ports`, so a server that spreads
  itself over a port range can be used at full strength. Both the dash and
  colon separator forms are accepted; a range naming no legal port is dropped
  the way a bad `upmbps` is, so one wrong node cannot stop the rest of the
  subscription — or the core itself — from working.

## Bug Fixes

- Review fixes for the two features above: an out-of-range or inverted hop
  range no longer reaches the core config (it would have stopped the whole
  core from starting); deleting a subscription while its edit was being saved
  now says the row is gone instead of reporting a parse failure that never
  happened; and the "applies after reconnecting" toast suffix is translated
  in English instead of appending Chinese text to an English sentence.
- The system-proxy status line on the overview now has English wording on
  Windows and Linux too (it previously fell back to Chinese there), along
  with the other machine-state lines the api composes.

## 新功能

- **订阅可以编辑了。** 订阅页每一行多出一支铅笔：打开的就是导入表单，但已
  预填这一行自己的名称和订阅源，保存后原地更新——行、id、当前使用状态都保
  留。服务商改了订阅地址（或像 obfs 这样需要给 URI 补参数）时，不用再删了
  重加。解析失败时对话框不关、错误显示在字段下方，和导入一致；新源里消失
  的节点按刷新的同一套兜底处理；内核运行中保存会提示「重新连接后生效」。
- **认识端口跳跃范围了。** hysteria2 链接（或 Clash yaml 的代理）里带的跳
  跃范围——URI 的 `mport=20000-50000`、yaml 的 `ports:`——现在会传给内核的
  `server_ports`，端口跳跃的服务器可以满血使用。横杠和冒号两种分隔写法都
  认；写不出合法端口的范围按坏 `upmbps` 的同款处理丢弃，一个节点写错不会
  影响订阅里其他节点——更不会让整个内核起不来。

## 修复

- 上面两个功能的评审修复：越界或倒序的跳跃范围不再进入内核配置（否则会让
  整个内核启动失败）；保存编辑期间订阅被删除时，如实提示订阅已不在列表中，
  而不是谎报一次从未发生的解析失败；「重新连接后生效」后缀在英文界面里正
  常翻译，不再往英文句子后面接中文。
- 总览页的系统代理状态行在 Windows 和 Linux 上也有了英文文案（此前会漏出
  中文），api 拼接的其余机器状态行一并列全。
